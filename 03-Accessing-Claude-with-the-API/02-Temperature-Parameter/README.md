# 02 - Temperature Parameter 🌡️

Scopri come il parametro **temperature** influenza il comportamento di Claude.

## 🎯 Cosa Imparerai

- **Temperature 0.0** = Risposte determistiche e coerenti (sempre la stessa risposta)
- **Temperature 1.0** = Risposte creative e variate (risposte diverse ogni volta)
- Come scegliere la temperature giusta in base al task

## 🚀 Come Usare

### Versione Pulita
```bash
python3 temperature_demo.py
```

### Versione Con Commenti
```bash
python3 temperature_demo_explained.py
```

## 📊 Cosa Vedrai

Il demo genera idee di film a due diverse temperature:

1. **3 Risposte a Temperature 0.0** - Quasi identiche (deterministica)
2. **3 Risposte a Temperature 1.0** - Diverse tra loro (creativa)

## 🔑 Concetti Chiave

| Parametro | Temperature 0.0 | Temperature 1.0 |
|-----------|------------------|------------------|
| **Comportamento** | Deterministica | Casuale/Creativa |
| **Uso** | Estrazione dati, codice | Generazione creativa |
| **Risposte uguali?** | Sì (quasi sempre) | No (sempre diverse) |
| **Velocità** | Leggermente più veloce | Normale |

## 💡 Quando Usare Quale

### Temperature 0.0 (Deterministica)
✅ Estrazione di dati da testi  
✅ Generazione di codice  
✅ Risposte strutturate e coerenti  
✅ Query di database  

### Temperature 1.0 (Creativa)
✅ Generazione di contenuti creativi  
✅ Brainstorming di idee  
✅ Storie e poesia  
✅ Copywriting
